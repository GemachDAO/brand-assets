# Gemach brand assets

Stable, public URLs for Gemach and GDEX logos, for directory listings (DefiLlama, chain ecosystem pages, explorers, MCP registries) and press.

| File | Use |
|---|---|
| `logos/gdex/gdex-icon-1024.png` (also `-512`, `-256`, `.svg`) | GDEX listing icon: white Gemach lion on Rich Black `#060A17`. Safe for round crops. |
| `logos/lion/gemach-lion.svg` | Master lion mark, `fill="currentColor"` (recolorable) |
| `logos/lion/gemach-lion-white.svg`, `gemach-lion-black.svg`, `gemach-lion-black-1024.png` | Lion on transparent background |
| `logos/gemach-lockup-white-on-dark.png`, `gemach-lockup-black-on-light.png` | Lion + GEMACH wordmark |

Raw URL pattern: `https://raw.githubusercontent.com/GemachDAO/brand-assets/main/<path>`

Rules: don't stretch, rotate, or add effects to the mark. Light mark on dark, dark mark on light. Brand colors: Rich Black `#060A17`, white `#FFFFFF`.

Links: https://gemach.io · https://gdex.pro · https://docs.gemach.io · https://twitter.com/gemach_io
